# Deployment

The hosted demo runs on three free services:

| Part | Where | Address |
| --- | --- | --- |
| Web app (Next.js) | Render web service `salesway-web`, Singapore | https://salesway-web.onrender.com |
| API (FastAPI) | Render web service `salesway-api`, Singapore | https://salesway-api.onrender.com (docs at `/docs`) |
| Database | Neon Postgres, AWS Singapore (pooled connection) | — |

`render.yaml` describes both Render services. Every push to `main` redeploys them; the API runs
`alembic upgrade head` before starting, so new migrations apply automatically.

## First-time setup

1. **Neon:** create a project in AWS Asia Pacific (Singapore) and copy its connection string.
2. **Load the database** from your computer (once): put `DATABASE_URL=<the string>` in
   `backend/.env.neon` (git-ignored), then run the migrations and the seed with that URL. The
   app accepts Neon's `postgresql://` form as-is.
3. **Render:** Dashboard → New → Blueprint → pick the `juhis30/salesway-ai` repository → Render
   reads `render.yaml` and asks for `DATABASE_URL` (paste the same Neon string) → Apply.
   `JWT_SECRET` is generated by Render.

## Things to know

* **Free servers sleep** after 15 minutes without visits; the first visit then takes about a minute
  while both services wake up. Neon also pauses when idle and wakes in a second or two.
* **Open demo:** anyone with the demo logins (in the README) can use and change the demo company.
  Rebuild it with fresh data up to today by running `python -m app.seed --reset` with
  `DATABASE_URL` from `backend/.env.neon`.
* **Data goes stale:** the demo data ends on the day it was seeded, so "this month" views empty
  out over time. Re-seed when you want to show it.
* **Addresses are fixed in `render.yaml`:** the web app's API address (`NEXT_PUBLIC_API_URL`, built
  into the app) and the API's allowed origin (`CORS_ORIGINS`). Change both if a service is renamed.
* **Not configured in production:** the Claude assistant (`LLM_PROVIDER=mock`) and real WhatsApp
  (`WHATSAPP_PROVIDER=mock`; webhooks are refused without `WHATSAPP_APP_SECRET`). Add those
  variables in Render's dashboard to switch them on.
* **Memory:** the free API instance has 512 MB; the app uses roughly 250–300 MB with pandas and
  scikit-learn loaded.
